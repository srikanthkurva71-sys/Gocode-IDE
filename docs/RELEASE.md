# Release Checklist

- [ ] Version and release notes reviewed.
- [ ] CI type-check/build passes.
- [ ] Unit, integration and end-to-end tests pass.
- [ ] Windows desktop build succeeds on a clean runner.
- [ ] Real filesystem, terminal, toolchain, Git and recovery features tested.
- [ ] Dependency/security advisories reviewed and triaged.
- [ ] MSI/package install, upgrade, uninstall and data preservation tested.
- [ ] Publisher/signing identity, metadata and artifact hashes verified.
- [ ] Privacy, support/issue page, license notices and third-party attribution ready.
- [ ] No secrets in logs or release artifacts.
- [ ] GitHub Release contains verified artifacts and checksums.
- [ ] Microsoft Partner Center submission completed.
- [ ] Certification decision received before claiming store approval.
