# Privacy Principles

- Gocode IDE is intended to remain free to use, with no mandatory account, subscription, or advertising.
- Core editing should work locally without cloud sign-in.
- Project files must not be uploaded automatically.
- Optional AI/cloud integrations disclose the provider, content transmitted, and provider-specific terms or charges before the user confirms.
- Telemetry is off by default.
- Users review support bundles before sharing; secrets and environment variables must be redacted.
- Workspace and settings export should be available.
- Free of charge does not automatically mean an extension is open source; publisher and license must be shown.
